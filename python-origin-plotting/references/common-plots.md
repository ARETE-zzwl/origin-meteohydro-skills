# 常见气象水文科研图配方

`assets/common_plot_gallery.png`与`scripts/make_gallery.py`展示固定种子的合成示例。不是本项目结果，也不是训练/检验；原生Origin例子另由originpro_plot_template.py生成。不要用示意场替代实际地图或重建缺失数据。

| 图型 | 需要的数据 | 首要表达与检查 | 工具建议 |
|---|---|---|---|
| 距平填色＋环流等值线＋风矢量 | lat/lon、标量场、u/v、单位、掩膜 | 同层/同日窗；投影变换；矢量参考箭头；距平中心0；下采样仅改显示密度 | 有真实地理投影优先Cartopy/NCL；Origin需正确坐标 |
| 降水分级空间图 | 网格值、累计时段、陆海/缺测掩膜 | 非均匀bin、NaN≠0、colorbar完整标界；原分辨率不伪装高分辨率 | 地理工具或原生矩阵图 |
| 纬度—气压/经度—气压剖面 | 2D场、hPa、经纬度、地形掩膜 | 气压向上递减，通常log轴；地下层不显示；垂直箭头比例注明 | Origin矩阵/等值线或Python |
| Hovmöller图 | 时间×经/纬向场、平均范围 | 先固定平均纬带与权重；时间轴方向、跨年/日界；不把传播斜率当因果 | Origin矩阵热图或Python |
| 事件相对日合成 | lag、均值、lo/hi、样本数 | t=0含义、各lag缺测支持；区间是SD/SE/CI或同时区间；自相关/空间依赖由上游分析处理 | Origin原生线/点＋带/端点 |
| 点区间/森林图 | estimate、lo、hi、组、n、校正P | 保留不对称区间与零线；效应量优先；P值family不能换；RR参考线1 | Origin优先 |
| 降雨—径流过程图 | time、雨量、观测/模拟流量 | 降雨柱在上、流量线在下共享时间；单位分开；时移对齐和峰时差 | Origin多层/多面板 |
| 流量历时曲线FDC | 有效流量序列、期间/季节 | 统一有效期、排除缺测；降序，超越概率i/(n+1)；logQ只用于正流量，零流量另注 | Origin排序输入/对数Y |
| 观测—模拟散点/密度 | 配对有效obs/sim、单位、检验期 | 相同x/y范围和1:1线；注明n；高密度用hexbin；相关不代表无偏 | Origin散点/密度或Python |
| 可靠度图＋概率直方图 | 概率、二元事件、分箱、事件基率 | bin计数、空bin、区间及独立检验；稀有事件同时PR-AUC，ROC不单独包办 | Origin读上游表，别绘图时重新挑bin |
| Taylor图 | 相同支持的r、SD、centered RMSE | 必须交代标准化、负相关显示范围；不展示均值偏差，需辅以bias/RMSE表 | 经验证模板/脚本，不硬拼极坐标 |
| EOF空间型＋PC时间序列 | 训练期EOF/PC、权重、方差贡献 | 正负号可整体翻转但空间型/PC同步；说明单位和训练期，不能用全期EOF作独立预测证据 | 地图＋Origin时间序列 |

## 通用排版

一图一个明确结论；a/b面板按证据读序，不按程序输出顺序。相同比较量共享尺度，物理量不同不强迫共轴。180mm、8pt可作为初始双栏草图，最终跟随目标期刊；留足colorbar/脚注空间。浅色区间＋实线中心；类别用有色符号而不是巨大柱体。显著性hatching/stippling稀疏且覆盖规则固定，说明多重检验与场显著性，不以星号代替效应量。

真实地图需核对投影、经度0–360或−180–180、纬度方向、实际grid中心/边界及矢量旋转；海岸/国界使用来源明确且本地可用的底图，不因绘图库首次运行默默下载地理资产。若没有底图，明确仅做坐标示意，不画假国界。

## 上游数据契约

本skill不选择新的最显著lag、阈值或案例；只消费已有统计结果。若上游区间含非有限值，指出不可估，不替换0；效应估计落在百分位CI之外也可能有统计原因，应保留并请求核实，而不是强制对称修正。区间端点渲染本身只要求lo≤hi，绝不能仅为通过绘图测试移动估计。

传统图例参考可查[NCAR/NCL应用示例](https://www.ncl.ucar.edu/Applications/)、[Matplotlib统计图库](https://matplotlib.org/stable/gallery/statistics/index.html)。实际论文图不受合成示例限定。
