# 图件审查：先科学含义，再版面

使用时机：完成图型选择后确认数据语义；导出前按本页复核。依据[30篇文献](literature-30.md)，R编号见[期刊图型配方](journal-figure-recipes.md)。以下是本技能的检查流程，不替代目标期刊投稿要求。

## 1. 图与科学问题对应

- 一句话写清比较对象、检验期与图要支持的结论。先给主要证据，再给总分、稳健性或机制解释。
- 多模型比较保留相同流域/事件的配对键。跨流域分布、跨成员分布、重训变异、观测误差分别命名。
- 总分高不代表高流、低流、洪峰时间和概率校准同时好。按问题补充诊断，避免无目的堆满面板。（P03–P15）

## 2. 坐标与统计语义

- 标出单位、累计时长、日历、水文年起点、时区和基期中与当前图相关的项。
- Q95必须说明是非超越95%分位还是超越95%流量，二者高低流含义相反。FDC的排序信息不能支持峰时结论。（P05–P06、P11）
- NSE/KGE不强制限制[0,1]。任何轴截断、对数变换、异常点省略都需明确交代；对数轴不能无声删除0或负数。（P03、P07、P13）
- 区间写实际定义：SD、SE、CI、预测分位或成员分位。显示原始不对称端点；效应点落在某些bootstrap区间外时请求核实，不能为画图强制移动。（P10、P17、P27）
- 每个lag、分箱或分组都能追溯样本数。空分箱不画为0；不在画图阶段重新选阈值、最佳lag或最显著时窗。（P11–P15、P19–P22）

## 3. 颜色与比较

- 非负量用顺序，物理中点的正负变化用发散，角度/季节相位用循环，分类用离散。风险比中点是1；若绘制log风险比，中点才是0。
- 同变量比较固定色阶、单位、参考期与缺测样式；有不同尺度需求时清楚分面标注。（P01–P02）
- 缺测、无事件、非显著和真实0不共用一种白色编码。差值图的白色零值与灰色缺测分开。
- 点状覆盖逐一命名：p值、符号一致性、超出集合基准或其他定义。论文中的点状纹理并非都表示显著性。（P18、P22、P30）
- 保留一份灰度预览；关键类别配线型或符号。论文印刷图不依赖屏幕高饱和度才能读懂。（P01–P02）

## 4. 多面板结构

- 数据概况放样本覆盖、时间支持和必要变量分布；避免把地图当装饰。（P11）
- 多个过程变量优先共享X的上下层，避免双Y轴造成曲线相关性的视觉暗示。
- 图例顺序固定，观测/基准视觉角色稳定；重点模型突出，其余模型可用浅灰但仍可追溯。
- 热图显示同样的行列顺序；多参考数据集可做两个简单面板，无可靠模板时不强制双三角单元。（P16–P18）
- 气泡大小明确按面积编码，故事线保持成员连续，小波箭头解释变量顺序。（P25、P27–P30）

## 5. 原生工程与导出

- 原始/审计表、绘图整理表、统计来源分开保存；数据副本没有联动公式时明确说明。
- 保存OPJU，再复开检查行数、关键端点、系列数和缺测断线；不能仅凭保存成功验收。
- 明确目标期刊、最终尺寸、字体与格式。未给期刊时用现有草图尺寸起步，不将180 mm/8 pt写成通用投稿标准。
- 图中文字优先可编辑/矢量；密集点和热图可按需要栅格化。检查成品而不只看Origin画布：裁切、单位上标、透明度、线宽、字体、实际尺寸与缩版可读性。
- 原生API、模板或导出没有实测时，交付记录使用“配方已整理/待本机验证”，不能使用“全部图型已支持”。

## 图注最小模板

“（a）[对象/变量/单位]，比较[组别]，使用[期间与有效样本]；（b）[配套诊断]。线/点表示[统计量]，阴影为[实际区间定义及估计单位]；参考线表示[基准]。颜色/纹理表示[含义]，缺测用[样式]。阈值、聚合和检验方法为[已确定定义]。数据来源：[标识]。”

删去不适用项；如图中没有统计检验，不添加“显著”等词。合成示例必须写“SYNTHETIC / 仅演示”，不得标成论文结果。
