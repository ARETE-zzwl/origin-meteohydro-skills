# 期刊图型配方：从科研问题到Origin数据表

依据：新增[30篇文献与阅读定位](literature-30.md)，编号P01–P30。以下是本技能从论文中提炼的图形决策与实现建议，不是任何期刊的统一规范；不复制论文图片或替用户重新计算统计结果。

原有12类基础图见[common-plots.md](common-plots.md)。本页增加R13–R24，并细化常用图的证据组合。每次只读当前任务对应条目。

## 先选证据组合

| 科研问题 | 建议的主图与配套诊断 | 阅读依据 |
|---|---|---|
| 模型在哪些流域改善 | 技能ECDF＋同流域配对差值；必要时加空间分布 | P07–P09 |
| 高分是否掩盖洪峰或枯水问题 | 过程线＋FDC＋峰时/高低流误差分量 | P03–P06、P12 |
| 概率预测是否可信 | 校准图＋分箱样本数＋离散度/误差；再报适用评分 | P10、P14–P15 |
| 极端事件如何演变 | 阈值定义示意＋事件条带＋持续/强度/频次分面 | P19、P21、P25 |
| 干旱何时传递到径流或土壤 | 先区别相关响应时间和事件滞后，再画矩阵或点区间 | P22 |
| 集合情景有多大分歧 | 单成员背景＋明确定义的分位带＋可追踪故事线 | P17–P18、P26–P27、P30 |
| 季节与遥相关结构是什么 | 圆形季节图或时频图，配样本支持与检验定义 | P23–P24、P28–P29 |

## 新增12类配方

### R13 · 跨流域技能ECDF

- 输入：`basin_id, model, metric, value, split`，或上游已算好的`metric_value, cumulative_probability, model`；不同模型使用同一有效流域集合或报告差异。
- Origin：每模型一组X–Y阶梯线；Y为累计比例，标签注明`P(metric ≤ x)`。高分更好的指标在同一X处累计比例较低通常更优，低分更好的指标相反，不能只凭曲线“更高”判断。
- 配套：R14配对改进、失败流域比例与样本数。NSE/KGE允许负数，不默认截断到[0,1]；若主图截断，报告截断数、最小值并提供完整范围补图。
- 依据：P07 Figures 8/14；P08 Figures 3–6；P09 Figure 3。ECDF连接方式应与实际分布定义一致，不用样条制造分辨率。

### R14 · 配对技能改进与误差分量

- 输入：`basin_id, metric, baseline, candidate, delta, split`；`delta`的符号定义在图注中固定。CI由上游提供，不在绘图时筛选显著流域。
- Origin：按固定分组或预先声明的规则排列流域，点区间图展示差值；零线为无变化。误差分量可另设小面板，避免把单位不同的指标相加。
- KGE要写版本、相关项、变异项、偏差项和基准。原始KGE的均值流量基准为`1−√2`，仅在该定义及对应条件下使用；不是所有KGE版本的合格线。Taylor图不能替代均值偏差诊断。
- 依据：P03、P04、P12–P13。DE极坐标需经验证的统计实现和编码图例，缺失时退回分量点图。

### R15 · 模型×指标portrait矩阵

- 输入：`model, metric, reference, value, better, status`，另附标准化公式和模型清单。一个指标可能有多个参考数据集。
- Origin：优先按参考数据集分面做热图；固定模型/指标排序与色阶。矩阵转换不得默认聚合重复单元。参考值为0的偏差图用发散色标；非负绝对误差用顺序色标。
- 若采用`(error − ensemble_median)/ensemble_median`等相对指标，明确分母为0的处理，保留原始误差表。改变模型集合会改变中位数和颜色。缺失格用单独样式，不着色成0。
- 双三角单元在Origin中需额外对象或模板；没有经过验证的模板时用两个普通矩阵，避免手工三角形与数据脱节。
- 依据：P16 Figure 1、P17 Figure 7、P18 Figure 8。

### R16 · 校准曲线、偏差图与分箱支持

- 二元事件可靠度输入：`bin_left, bin_right, mean_probability, event_frequency, n`；固定阈值、时效与检验样本。横坐标用箱内平均预测概率，不自动用箱中心替代。
- Origin：上面画可靠度点线与1:1线，下面画同一分箱的样本数；两层X范围一致。空箱不连成0，不加伪计数。附区间时标明Wilson、bootstrap或其他实际方法。
- 连续预测分布的概率图/PIT诊断另用上游分位/概率表；不能把它与二元事件可靠度混为一种图。偏差副图可显示相对1:1线的有符号距离。
- sharpness描述预测概率分布，resolution是评分分解概念；样本直方图不能单独证明resolution。校准良好也不必然有预测技巧。
- 依据：P10 Figures 2/8–9、P14 Figures 5–7/19、P15 Figures 4/10。

### R17 · 集合秩直方图与spread–error

- 输入：`rank, count, ensemble_size`及`lead, spread, rmse, n`；成员数、并列值处理、观测误差和配对规则由上游说明。
- Origin：秩直方图标理想参考频率`1/(M+1)`，成立条件是固定M、适当处理并列且检验定义匹配；spread与RMSE同单位并按时效或已定分箱展示。
- U形、倾斜或拱形是需要进一步检查的现象；样本依赖、条件分组和观测误差也会影响形状。不得只凭秩均匀宣称模型“可靠且准确”。
- 依据：P14 Figures 7/19；P15 Figures 2/4/8–11。

### R18 · 特征趋势与场显著性分面

- 输入：每种特征单独的`time, estimate, lo, hi, n`或网格趋势、有效掩膜与检验掩膜；附每年/每十年等趋势单位。
- 频次、历时、强度、范围分别画，不能共用无量纲化但未说明的纵轴。模型符号一致性、逐点p值、场显著性和“超过基准集合误差”使用不同图例术语。
- 多重比较、自相关修正和显著性家族在上游决定。绘图层不补算最显著时窗或修改掩膜；非显著值仍可有有用效应量。
- 依据：P18 Figures 5–6、P22 Figures 3/8、P25 Figure 4、P30 Figures 2–3。气泡表达面积或事件量时让符号面积与值成比例，提供尺寸图例。

### R19 · 复合事件阈值象限与尾依赖

- 输入：配对的变量X/Y、阈值及单位，或上游拟合好的联合等值线/尾依赖与CI；保留事件标识。
- Origin：原始变量散点配两条阈值线和四类事件符号；高密度时用明确聚合定义的密度图。原始边际、概率边际和变换边际分别展示，不能沿用同一单位。
- 尾依赖曲线的X为分位阈值；标样本支持、时空容差窗口与区间方法。普通相关、联合概率、条件概率、风险比各自命名；风险比中性值为1。
- 依据：P19 Figure 2、P20 Figures 3–7、P21 Figure 7。若尾部样本不足，保留“不足以估计”，不通过拟合平滑掩盖。

### R20 · 事件时间条带与相对日合成

- 输入：`event_id, start, end, anchor, type`与配套连续时间序列；合成另用`lag, estimate, lo, hi, n`。
- Origin：多层共享时间轴，上层变量与阈值，中层事件条带，下层响应或支持数量。`t=0`说明是开始、峰值或结束；热后雨与同时复合事件不可混用。
- 每个lag保留有效事件数。区间缺失处断开，不能跨缺口连续填色；频次、平均强度与积分严重度分开。事件筛选规则在图注或方法中可追溯。
- 依据：P19 Figure 3、P21 Figure 1、P27 Figures 2–7。论文阈值作为案例，不复制为默认业务标准。

### R21 · 干旱响应/滞后矩阵

- 输入：`source_type, target_type, season, dataset, timescale_or_lag, value, valid`及各类时间的定义。
- Origin：矩阵或分组点区间；按数据集分面，相关响应时间与事件起始滞后分开。响应方向标清“气象→径流”等，不因相关而画成已确证因果链。
- 缺测、未发生事件、未达到检验要求和真实0使用不同标识。数据集差异可用MAD等摘要；不在均值近0时无条件报告CV。
- 依据：P22 Sections 2.3–2.6及Figures 2–8。

### R22 · 圆形季节性与事件类型

- 输入：上游圆形均值日期、集中度R、有效年数，或明确处理闰年后的日期角度与事件分类。
- Origin：极坐标散点，角度表示日期、半径表示R时必须在图例明说；若半径表示频次则不能再解释为集中度。方向、零点和水文年起点显式标注。
- 双峰用月份分布或两个峰补充，接近均匀的样本不突出“平均洪水日”。跨年日期不能按普通算术平均；类别占比附原始次数。
- 依据：P23 Sections 3.1/3.3和Figure 10；P24 Figures 4/6/8/10。

### R23 · 小波功率/相干与QBO时高图

- 小波输入：`time, period, power_or_coherence`，另有COI、显著性掩膜和相位角；全部由已确定的分析程序产生。
- Origin：矩阵热图/等值线，周期通常用log2等对数刻度并标实际周期单位；COI用淡化或边界注明。相干值用[0,1]顺序色标，功率的尺度及标准化另说明。
- 相位箭头需说明变量顺序、角度定义及“谁领先谁”；箭头下采样只改变显示密度。逐点与区域显著性不能混称。
- QBO另用`time × pressure`纬带平均风场；注明纬带、权重、气压方向与单位，0中心发散，不能用小波的周期轴标签。
- 依据：P28 Figures 1–5、P29 Section 2.2/Figures 7–12、P16 Figure 4。未有可靠地理底图或变换时不假称Origin具备完整地理投影。

### R24 · 集合分位带与物理故事线

- 输入：固定情景与成员列表、`time, q05, q25, q50, q75, q95`以及单成员轨迹；每条带标清是成员分布、预测分布还是统计CI。
- Origin：从外层到内层绘制上下界带，叠加中位数和观测；避免重复填色使重叠区域被误读为更高概率。缺失片段断开。
- 物理故事线按驱动组合做小面板，标基期、每K归一化和是否已经加回多模式平均。选定成员后沿整个事件追踪，不能逐月拼接不同成员的极值。
- FDC情景族可用背景细线＋少量重点线，但情景包络不是概率区间。
- 依据：P10 Figure 10、P17 Figure 6、P18 Figures 2–3、P26 Figures 3–4、P27 Figures 2–7、P30及Appendix C。

## Origin实施边界与官方入口

以下是能力核对与手工实施入口，不等于本包已经自动化或实测了24种原生图。

| 动作 | 实施方式与注意点 | 官方入口 |
|---|---|---|
| 多系列/多层 | 用Plot Setup选定明确X/Y列及目标层；日期解析后核对首尾与时间间隔 | [Adding a Data Plot](https://docs.originlab.com/tutorials/adding-plot/) |
| 区间带 | 上下界必须共享X支持；填到下一数据曲线前检查曲线顺序，缺测分段 | [Fill Partial Area Between Curves](https://docs.originlab.com/tutorials/fill-partial-area-between-curves/) |
| 热图 | 完整规则网格用矩阵/虚拟矩阵；XYZ分箱会改变数据表达，不能未经说明就用默认聚合 | [Heatmap](https://docs.originlab.com/origin-help/heat_map)、[Virtual Matrix](https://docs.originlab.com/tutorials/heat-map-virtual) |
| 曲线连接 | ECDF保持阶梯，事件离散样本优先直线；平滑方式不制造观测点 | [Line Tab](https://docs.originlab.com/origin-help/pd-dialog-line-tab/) |

本包已提供的原生自动化仍是点区间模板。上述新配方需按安装版本制作原生模板并保存复开后再标记为实测。先用[输入检查与示例](data-contracts.md)确认数据语义，再做视觉调整。
